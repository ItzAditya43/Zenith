What's inside

Everything you open an AI app for.

A daily-driver workspace, not a chatbot demo. Pick the parts you need; the rest stays out of the way.

Code with an editor beside the chat

Open a project and get files, an editor and a terminal next to the conversation. The agent reads, edits and runs your code; every change appears as a diff and waits for your approval. Commit, branch and push from the Changes tab.

agent › edit src/auth.py +12 −3
approve? [ apply ] [ reject ]
git › commit "fix token refresh" ✓

Desktop control

Press Super Space anywhere and tell Zenith what to do: open apps, switch windows, type, click a button by name. It asks before every action.

Chat that does more

Paste images, attach documents, compare models side by side, or ask a council of models. Edit any message and keep every branch.

Deep research

Plans, searches, reads and writes a cited report you can reopen and question. It won't answer before it has searched.

Memory & documents

Remembers durable facts about you and cites your own files. Review or forget anything.

Ollama first, APIs when you want

Run local models with Ollama and browse its library in-app. Add OpenAI, Claude, Gemini, OpenRouter, Groq, DeepSeek, Mistral or any compatible server from Settings. API models are never picked automatically.

Voice in and out

Hold the mic to talk, hear replies read back, or go hands-free. Speech runs on your machine.

MCP, both ways

Connect any MCP server, or expose Zenith's memory and notes to other assistants.

Automation

Triggers, webhooks, scheduled prompts and folder watching, running on real events.

Privacy

Nothing leaves unless you send it.

Most AI apps run on someone else's computer. Zenith runs on yours, with a few clearly marked exceptions you switch on yourself.

Typical cloud assistant

  • Everything you type goes to a remote server
  • Your data may be logged or used for training
  • A subscription, rate limits or a paywall
  • An account tied to your identity

Zenith

  • Runs on your hardware against your local models
  • No account, no telemetry, no analytics
  • Passcode lock and AES-256-GCM encrypted credentials
  • Open source under AGPL-3.0, free for good

The exceptions: web search, reading a URL you give it, and any API or Ollama Cloud model you choose to use. Those send that message to the provider, and only when you pick them. API keys are encrypted on your machine and never shown again.

Before you install

What hardware do you need?

Zenith itself is light. The real requirement is the model you choose to run. Settings → Model routing scores your installed models against your actual GPU and RAM.

VRAM (or RAM, CPU-only)ComfortableStill usable
No GPU / under 4 GB1–2B paramsup to ~3B
4–8 GB (RTX 3050/3060 laptop)3–4B paramsup to ~8B
8–16 GB (RTX 4060 Ti / 4070)8–12B paramsup to ~20B
16 GB+ (RTX 4090, workstation)20B+ paramswhatever fits

A rough rule: about 0.65 GB per billion parameters at Q4, plus overhead. A model too big for your GPU spills onto slower CPU inference rather than failing, and Zenith's watchdog reports it instead of leaving you at a spinner.

FAQ

Common questions.

Is it actually free?

Yes. Zenith is open source under AGPL-3.0, with no subscription, paid tier or usage limits. Your only cost is your computer's electricity. If you add an API provider, that provider bills you directly, and only for what you choose to send.

Does my data leave my computer?

Not by default. Zenith talks to your local Ollama. Web search, reading a page you asked for, and any API or cloud model you pick are the only things that go out, and only for the message where you choose them. There is no telemetry and no account.

Do I need a powerful GPU?

No. It runs on CPU-only machines, just more slowly. See the hardware guide above; even modest laptop GPUs handle small models comfortably.

Can the desktop control feature do damage?

It's off until you enable it, it asks before every action, and it refuses to type into password managers. You can turn it off at any time in Settings → Agent tools.

Can I use it on my phone?

Yes. It's an installable web app with a mobile layout. Open it over your LAN or Tailscale and add it to your home screen.

What does the license mean in plain terms?

AGPL-3.0-or-later: use, modify and self-host freely. If you run a modified version as a network service for others, you must publish your changes.

Is it affiliated with Ollama?

No. Zenith is an independent client that talks to Ollama's local API like any other app on your machine.
